# 模組操作 SOP

## 組員操作步驟
1. 複製 *M_SOP* 到自己的本機
2. 修改資料夾名稱: 把 *M_SOP* 改成 *M_你的專案名稱*
3. 把自己做的專案放進 *M_你的專案名稱\ProjectContent*
4. 將 *M_你的專案名稱* 交給整合負責人

================================
## 結構說明
M_Name/
├─ ProjectContent/   放組員自己的遊戲內容
└─ Adapter/          萬用轉接頭


***這個專案結構的核心用意，就是先建立一個「完整主遊戲的母架構」，而 8 關只是之後插進去的內容模組***
