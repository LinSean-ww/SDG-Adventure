# 開發報告索引

此處保留 M2、M3、C3 場景與 M6 的 Markdown 報告，供組員閱讀設計決策與測試界線。

完整原始報告、其相對連結指向的截圖／CSV／XML／日誌、舊版快照及 Windows Build，保存在正式母專案外部的 `SDG Adventure_M4B_Backup_20261027/DevelopmentReports/`。此處僅複製長期閱讀的 Markdown，因此舊報告中的相對證據連結可能需要到外部保存區開啟原始版本。不要把大型產物複製回 Unity `Assets`。

每份舊報告記錄的是當時測試範圍；自動化 PASS 不代表後續目錄遷移或人工鍵鼠驗收也已 PASS。M4-B 的最新驗收狀態以外部最終審核報告與檢核表為準。

M4-B Final 起，`05_Testing` 的 Editor／PlayMode 工具新產物使用 `SDG_ADVENTURE_TEST_OUTPUT_ROOT` 或專案同層的 `<專案名>_TestOutputs`。本目錄只保留歷史 Markdown 閱讀副本，不接收新測試輸出。
